6. Major Projects
JARVIS — Personal AI Assistant
Aniket is building a personal AI assistant named JARVIS as a long-term engineering project.
Architecture includes a Windows laptop/backend and a Vivo V29 Android client, with communication using WebSocket; a PWA/Tailscale approach has also been used for practical mobile access.
The project is designed around local-first intelligence, tool/agent execution, memory, RAG, safety controls, adaptive learning, and future fine-tuning.
The system uses a multi-provider AI router, memory sanitization and half-life decay, granular permissions, adaptive learning with a safety firewall, and structured audit logging.
JARVIS must distinguish REAL, MOCK, and DEGRADED execution states and must not claim an action succeeded without observable evidence.
Safety architecture uses two independent gates: identity match plus explicit confirmation. DENY cannot be overridden by confirmation, and sensitive/destructive actions require explicit confirmation.
Adaptive learning must never modify or bypass safety gates, permissions, confirmations, destructive-action controls, restricted access, or external side effects.
Code changes follow a proposal → approval workflow.
Wake-word architecture uses Sherpa-ONNX as the authoritative Android wake-word runtime. Wake words must remain user-selectable/custom and must never be hard-coded to only 'Hey Jarvis'.
Current JARVIS direction includes both RAG and eventual LoRA/QLoRA fine-tuning. The current fine-tuning target is Qwen3.5-4B-Instruct, with QLoRA/LoRA and eventual local GGUF/Ollama deployment.
FaceSnap — AI Smart Attendance System
Multimodal attendance system combining face recognition and voice verification.

Streamlit is used for the application interface/resource caching, with MySQL used for data management.
Attendance is determined from combined face and voice recognition.

7. Current JARVIS Engineering Status
Free Web Skills are integrated: DuckDuckGo search, Wikipedia summaries, and Open-Meteo weather, designed for ₹0/API-key-free operation.
FastAPI gateway integration was merged while preserving the existing mobile contract and exposing skill/memory endpoints.
